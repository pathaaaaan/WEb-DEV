The Simple Times

This is the easiest way to make a newspaper. By using column-count, the text will automatically flow from the bottom of the first column to the top of the second. You don't have to manually split your text!

If you add more text, the browser does the work for you. In the old days, web designers had to use complex boxes or "floats" to do this, but modern CSS makes it a single line of code.

Just remember: the column-span: all property is what keeps the headline at the top instead of squishing it into the first column. Try changing the number in column-count to 2 or 4 to see how it reacts!
